Optional interviewee portraits.

Filename = the person's name in lowercase with hyphens, e.g.
  Jiayi Liu    -> jiayi-liu.jpg
  Aryton Shi   -> aryton-shi.jpg
  Florian Gao  -> florian-gao.jpg
  Haoge Shi    -> haoge-shi.jpg
  Jiahao Bai   -> jiahao-bai.jpg
  Alexander    -> alexander.jpg
  Binzer       -> binzer.jpg
  Kinno        -> kinno.jpg

Square images work best (they are cropped to 1:1).
No photo? The card shows the person's initial instead - nothing breaks.
Please get each person's consent before publishing their photo.
